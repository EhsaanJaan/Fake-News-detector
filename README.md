# Fake-News-detector
A Machine learning fake news detector using classification techniques. A range of models and an ensemble system were used on the WELFake dataset to produce the fake news detector.


FYP.ipynb merely shows all of the code that went into the creation of this project. This includes the training of the models on the dataset, which is then saved to SavedFyp.ipynb. 

To run this project, first run pip install -r requirements.txt with this directory open, then go into SavedFyp.ipynb and run.
